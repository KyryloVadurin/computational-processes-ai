* а) Навчальний датасет містить розмічені пари: вектор вхідних ознак $x_i$ та істинний цільовий маркер $y_i$
* б) Модель навчається без розмічених даних, виявляючи приховані кластери
* в) Агент взаємодіє із середовищем і отримує лише скалярні винагороди
* г) Вагові коефіцієнти моделі задаються інженером вручну і не змінюються

**2. Чим задача регресії відрізняється від задачі класифікації у Supervised Learning?**
* а) Регресія працює без розмічених даних, а класифікація вимагає вчителя
* б) Регресія прогнозує неперервні дійсні значення, а класифікація — дискретні категорії
* в) Регресія використовується лише для текстів, а класифікація — для зображень
* г) Між ними немає жодної математичної відмінності

**3. Які задачі належать до парадигми навчання без учителя (Unsupervised Learning)?**
* а) Прогнозування неперервних часових рядів та цінового графіка
* б) Кластеризація, зменшення розмірності та виявлення аномалій
* в) Бінарна класифікація електронних листів на спам та не-спам
* г) Оптимізація поведінки робота на основі функції винагороди

**4. Які компоненти утворюють математичний фреймворк навчання з підкріпленням (Reinforcement Learning)?**
* а) Вхідні ознаки, Класифікатор, Похибка MSE та Матриця Гесіана
* б) Навчальна вибірка, Тестова вибірка, Валідаційна вибірка та K-Fold
* в) Агент, Середовище, Стан (State), Дія (Action), Винагорода (Reward) та Стратегія (Policy)
* г) Згортковий шар, Повнозв'язний шар, Max Pooling та Softmax

**5. Як виражається середня квадратична функція втрат (MSE) для $N$ об'єктів у задачі регресії?**
* а) $L_{\text{MSE}} = \frac{1}{N} \sum (y_i - \hat{y}_i)^2$
* б) $L_{\text{MSE}} = \frac{1}{N} \sum |y_i - \hat{y}_i|$
* в) $L_{\text{MSE}} = -\frac{1}{N} \sum y_i \log(\hat{y}_i)$
* г) $L_{\text{MSE}} = \sum w_j^2$

**6. Чому функція втрат MSE більш чутлива до викидів (Outliers) у даних, ніж MAE?**
* а) Через використання модуля абсолютного відхилення
* б) Через ділення на кількість класів $C$
* в) Через наявність квадрата відхилення, що квадратично збільшує штраф за великі похибки
* г) Через застосування функції Softmax

**7. Яке припущення щодо розподілу шуму у цільовій змінній відповідає мінімізації MSE за принципом максимізації правдоподібності (MLE)?**
* а) Розподіл Лапласа
* б) Гаусівський (Нормальний) розподіл шуму $\mathcal{N}(0, \sigma^2)$
* в) Бернуллівський розподіл
* г) Рівномірний розподіл

**8. Яка функція втрат використовується для бінарної класифікації при оцінці ймовірностей $\hat{y} \in (0, 1)$?**
* а) Середня квадратична помилка (MSE)
* б) Бінарна крос-ентропія (Binary Cross-Entropy / Log Loss)
* в) Середня абсолютна помилка (MAE)

**9. Мінімізація категоріальної крос-ентропії (CCE) математично еквівалентна мінімізації якої метрики відстані між розподілами?**

* в) Манхеттенської відстані L1
* г) Косинусної подібності (Cosine Similarity)

**10. Що таке перенавчання (Overfitting) у машинному навчанні?**
* а) Стан, коли модель має недостатню складність і показує високу похибку і на навчальних, і на тестових даних
* б) Ситуація, коли модель надмірно адаптується до шуму навчальної вибірки і втрачає здатність до узагальнення на нових даних
* в) Процес прискорення градієнтного спуску за допомогою моменту
* г) Автоматичний відбір ознак за допомогою L1-регуляризації

```python
class BahdanauAttention(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.W_a = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.v_a = nn.Parameter(torch.rand(hidden_dim))

        score = torch.tanh(self.W_a(lstm_outputs))
        attn_weights = torch.softmax(torch.matmul(score, self.v_a), dim=1)
        context = torch.bmm(attn_weights.unsqueeze(1), lstm_outputs).squeeze(1)
        return context, attn_weights
```
